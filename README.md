# Where Whale 공지 관리

**[새 공지 작성](https://github.com/TopFiddlesticksGap/Where-Whale-Notices/issues/new?template=notice.yml)** · **[공지 관리](https://github.com/TopFiddlesticksGap/Where-Whale-Notices/issues?q=is%3Aissue+label%3Anotice)** · **[게시 결과 확인](https://github.com/TopFiddlesticksGap/Where-Whale-Notices/actions/workflows/publish-notices.yml)**

## 새 공지 작성

1. 위의 **새 공지 작성**을 엽니다. GitHub에 로그인해주세요.
2. 제목과 본문을 작성합니다.
3. 본문 입력창의 첨부 버튼으로 사진을 선택합니다. PC에서는 사진을 끌어놓거나 붙여넣어도 됩니다.
4. **게시 상태**를 `게시`로 두고 **Submit new issue**를 누릅니다.

날짜, 공지 ID, 사진 주소, 게임 데이터 변환은 자동입니다. JSON 파일을 직접 편집하거나 사진 URL을 복사할 필요가 없습니다. 이 주소를 휴대폰에 북마크해두시면 됩니다.

GitHub의 자동 게시 작업이 끝나면 게임에 반영됩니다. 게임의 공지 창을 열거나 새로고침하면 최신 내용을 확인하며, GitHub 캐시와 통신 상태에 따라 지연될 수 있습니다.

## 기존 공지 수정과 게시 중단

| 원하는 작업 | 방법 |
|---|---|
| 글·사진 수정 | 공지 관리에서 해당 글을 열고 본문 옆 메뉴의 Edit로 수정한 뒤 저장합니다. |
| 임시저장 | 작성할 때 게시 상태를 임시저장으로 선택합니다. 기존 글은 Edit에서 게시 상태의 값을 임시저장으로 바꿉니다. |
| 다시 게시 | 게시 상태를 게시로 바꾸거나, 닫힌 게시글을 Reopen합니다. |
| 게임에서 내리기 | 해당 게시글에서 Close issue를 누릅니다. 글은 관리 화면에 보관됩니다. |
| 게시 실패 확인 | 게시 결과 확인에서 가장 최근 실행의 요약과 오류를 확인합니다. |

수정할 때 `### 본문`, `### 게시 상태` 구분 제목은 유지해주세요. 본문 내용과 상태 값만 바꾸면 됩니다. 본문의 수정은 같은 공지로 취급하며, 새 공지로 알리고 싶다면 새 글로 작성합니다.

임시저장은 게임에 표시하지 않는 상태입니다. GitHub 글 자체는 공개되므로 비공개 메모용으로 사용하지 마세요. 저장소 운영팀이 작성한 글만 게임에 게시되며, 일반 방문자의 글은 자동 게시하지 않습니다.

## 사진 처리

- PNG, JPG, WEBP 사진과 GIF, MP4, MP3를 합쳐서 최대 5개 첨부합니다.
- GitHub에서 첨부를 허용하는 용량 안에서 사진당 최대 20MB, 4천만 화소까지 처리합니다. HEIC는 JPG로 변환해 첨부해주세요.
- 휴대폰 사진의 방향을 보정하고 긴 변 1600px까지 자동 축소합니다. 게임에서 읽을 수 있는 PNG/JPG로 저장합니다.
- 사진은 본문 아래에 첨부 순서로 표시됩니다. 사진을 교체하려면 기존 첨부를 지우고 새로 첨부합니다.
- 처리한 사진은 images/generated에 자동 보관합니다. 직접 파일을 올리거나 주소를 관리하지 않아도 됩니다.
- 공개할 권한이 있는 사진만 사용하고, 필요한 출처는 본문에 적어주세요.

## 운영 구조

`공지 작성 화면 → 자동 검증·사진 처리 → 게임 공지 피드 → 인게임 목록·본문`

운영자는 GitHub 게시글만 관리합니다. notices.json과 images/generated는 자동 생성되는 결과물입니다. 기존에 직접 작성한 두 공지는 legacy-notices.json에 보존되어 함께 표시됩니다.

공지 최대 50개, 제목 128자, 본문 8,000자까지 표시합니다. 사진이나 글 형식이 잘못되면 자동 게시 작업에서 오류를 알리며 기존 게임 공지를 유지합니다. 자동화 코드와 처리 도구를 변경할 때는 테스트를 통과시켜주세요.

## 알림과 공지의 차이

이 기능은 게임 안의 공지를 갱신합니다. 출석·미접속 알림은 기기의 예약 알림입니다. 새 공지를 게임이 꺼진 휴대폰에도 즉시 알리려면 원격 푸시 연동이 별도로 필요합니다.

## 출처

GitHub Issues·Issue Forms·GitHub Actions를 사용합니다. 공식 actions/checkout은 MIT 라이선스이며, 사진 처리는 Pillow 13.0.0을 사용합니다. 출처와 고지는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 기록합니다.

## GIF, 동영상, 오디오 첨부

기존 클립 버튼에 PNG/JPG/WEBP/GIF/MP4/MP3 파일을 넣습니다. 첨부는 합쳐서 5개, 원본 파일은 각 20MB 이하입니다. GIF와 MP4는 60초 이하, MP3는 600초 이하로 준비합니다. 영상은 H.264/AAC MP4, 최대 720px/24fps로 변환하고 GIF는 소리 없는 반복 영상으로 변환합니다. 변환 결과는 12MB 이하입니다. 게임에서 재생 버튼을 누를 때만 다운로드하며, 동시에 하나만 재생합니다. 이 기능은 미디어 지원이 추가된 게임 빌드에서 사용할 수 있습니다. 기존 설치 APK에는 자동으로 코드가 추가되지 않습니다.

GitHub 첨부 방식: https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/attaching-files

## 공지 작성자 허용 목록

조직 멤버나 저장소 협업자가 아니어도 publishers.json의 users에 GitHub 계정명이 등록되어 있으면 공지를 게시할 수 있습니다. 현재 blekii1341, OCGK123 계정을 등록했습니다. 그 밖의 외부 계정 글은 게시하지 않습니다. 등록된 계정도 notice 라벨, 게시 상태 게시, 열린 게시글 조건을 충족해야 합니다.
