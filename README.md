# Where Whale 공지사항

이 저장소에는 공개 공지 글과 첨부 사진만 보관합니다. 게임 소스, 계정 정보, 인증 토큰을 올리지 마세요.

## 휴대폰에서 공지 작성

1. GitHub에 로그인하고 이 저장소의 `notices.json`을 엽니다.
2. 연필 모양의 편집 버튼을 누릅니다.
3. `notices` 배열에 공지를 추가하거나 기존 글을 수정합니다.
4. `Commit changes`로 `main` 브랜치에 저장합니다.

게임의 공지 창을 열거나 새로고침하면 최신 내용을 확인합니다. 공지 창을 열어 두면 약 60초마다 확인합니다. GitHub 캐시와 통신 상태에 따라 반영이 지연될 수 있습니다. 앱 업데이트나 Unity 에디터 실행은 필요하지 않습니다.

## 공지 형식

```json
{
  "id": "update-20261018",
  "date": "2026-10-18",
  "title": "업데이트 안내",
  "body": "첫 번째 문단입니다.\n\n두 번째 문단입니다.",
  "imageUrls": [
    "https://raw.githubusercontent.com/TopFiddlesticksGap/Where-Whale-Notices/main/images/update-20261018.png"
  ]
}
```

- `id`는 공지마다 다르게 작성합니다.
- `date`는 `YYYY-MM-DD` 형식입니다. 최신 날짜가 위에 표시됩니다.
- 제목은 128자, 본문은 8,000자, 공지는 최대 50개입니다.
- 문단은 `\n\n`으로 구분합니다. HTML이나 마크다운 대신 일반 텍스트를 사용합니다.
- 사진이 없으면 `imageUrls`는 빈 배열 `[]`로 둡니다.
- 특수문자나 이모지는 게임의 픽셀 폰트에서 표시되지 않을 수 있습니다.

## 사진 첨부

1. `images` 폴더에서 `Add file > Upload files`로 사진을 올립니다.
2. 짧은 영문 파일 이름을 사용합니다. 예: `update-20261018.png`.
3. 위 예시의 주소에서 파일 이름을 바꿔 `imageUrls`에 넣습니다.
4. 사진은 PNG 또는 JPG이며, 한 공지에 최대 5개입니다. 사진당 4MB 이하, 가로·세로 각각 4096px 이하로 준비합니다. 모바일 성능을 위해 1600px 안팎을 권장합니다.
5. 사진을 교체할 때는 새 파일 이름을 사용하면 캐시로 인해 옛 사진이 보이는 문제를 줄일 수 있습니다.

이 저장소의 사진은 누구나 볼 수 있습니다. 사용 권한이 있는 사진만 올리고, 필요한 출처·저작권 고지를 본문이나 별도 문서에 함께 기록하세요.

## 알림과 공지의 차이

이 피드는 게임 안의 공지사항을 갱신합니다. 출석·미접속 알림은 기기에서 예약하는 로컬 알림입니다. 새 공지를 게임이 꺼진 휴대폰에도 즉시 보내려면 Firebase Cloud Messaging 같은 원격 푸시 서비스가 별도로 필요합니다.
